# 02. 스탯 시스템

| 스탯 | 범위 | 역할 |
|---|---|---|
| 힘 (STR) | 1~20 | 공격력, 체력에 + 보정 |
| 지력 (INT) | 1~20 | 지식/지혜/판단력(선택지 힌트 노출 등), 체력에 − 보정 |
| 민첩 (AGI) | 1~20 | 회피율, 명중률, 손재주 판정 |
| 행운 (LUK) | 1~20 | 이벤트 결과의 행운/불행 확률 보정 |
| 체력 (HP) | 파생값 | 아래 공식 참고 |

## 생성 규칙

평균 5, 표준편차 2인 정규분포로 각 스탯을 굴려 1~20으로 클램프. 10% 확률로 "재능형" 캐릭터는 평균 7로 롤(분포만 이동, 범위는 동일). 구현: `src/engine/statGen.ts`의 `rollStat()`.

재굴림(리롤)은 **기본값: 허용 안 함** (랜덤성 자체가 이 게임의 컨셉). 단, `characterGen.ts`에 `allowReroll` 플래그를 두어 쉽게 켜고 끌 수 있게 구현한다.

## 체력 공식

```
HP = 30 + STR × 4 − INT × 2 + 신체보정
신체보정 = 나이곡선(나이) + 체형보정(키, 몸무게) + 직업보정
```

- **나이곡선**: 10대 후반~20대 중반을 전성기로 두고 그 이전/이후로 완만히 감소하는 곡선.
- **체형보정**: 과체중/저체중일수록 페널티, 표준 체형일수록 보너스 (BMI 기반 근사치 사용).
- **직업보정**: 육체노동/전투 계열 직업 +, 학자/상인 계열 직업 −.

구현: `src/engine/statGen.ts`의 `computeHP()`.

## 행운 판정

```
결과 확률 분포(좋음/보통/나쁨)에서 LUK 보정 = (LUK − 5) × 2%를 좋음 쪽에 더하고 나쁨 쪽에서 뺀다.
```

구현: `src/engine/statGen.ts`의 `applyLuckBias()`. AI 게임마스터 호출 시 이 보정된 분포를 프롬프트 컨텍스트에 힌트로 전달하고, 오프라인 폴백에서는 직접 이 분포로 결과를 샘플링한다.

# 06. 계승(레거시) 시스템

- **범위**: 로컬(기기) 저장 기반만 구현. 멀티유저 공유 풀은 서버 인프라가 필요해 이번 스코프에서는 제외한다 — 게임 소개 문서에 "추후 서버 기반 공유 풀로 확장" 비전으로만 기재.
- **트리거**: 캐릭터가 사망하거나 플레이어가 명시적으로 "포기"를 선택했을 때 해당 캐릭터를 "기록"으로 저장.
- **저장 데이터**: 이름, 생애 요약(누적 day_summary를 몇 줄로 압축), 최종 스탯, 사인/결말, 소지했던 대표 아이템 1~2개.
- **다음 플레이 시작 시**: 이 기록 중 일부(최근 N명, 랜덤 샘플)를 AI 프롬프트에 "과거 인물 목록"으로 주입해 조연/소문으로 자연스럽게 등장시킨다. 오프라인 폴백 생성기도 동일 목록을 참고해 상황 텍스트에 이름을 언급할 수 있다.

구현: `src/engine/legacyStore.ts` (`saveLegacy()`, `getLegacyRecords()`), 타입: `src/types/legacy.ts`. 저장소는 웹 환경에서 `localStorage`를 사용하는 `@react-native-async-storage/async-storage`의 웹 어댑터를 통해 이루어진다.

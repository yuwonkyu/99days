# 03. 캐릭터 생성 규칙

- 시작 시 이름을 직접 입력하거나 "랜덤 이름" 주사위 버튼으로 생성 가능. 지역/문화별 이름 풀이 이상적이나, 이번 스코프에서는 `src/data/names.ts`에 지역별 임시 이름 풀을 두고 이후 교체 가능하게 구조화한다.
- 랜덤 요소: 성격/성향, 직업, 체형(키/몸무게), 나이, 출생 지역(국가/문화권), 인간 또는 혼종 여부.
- 기본 종족은 인간이며, 혼종(돌연변이 혼혈) 옵션은 낮은 확률(약 5%)로 등장하도록 구현하고 이후 확장 가능하게 열어둔다.
- 출생 지역에 따라 직업 풀과 스탯 경향치가 다르게 적용된다 (`src/data/origins.ts`):
  - 북부 고원 국가: STR 경향 ↑
  - 강 중심 상업 도시: LUK/INT 경향 ↑
  - 숲의 부족 국가: AGI 경향 ↑
  - 동양풍 왕조 / 서양풍 봉건국가: 균형형, 직업 풀 차이 위주
  - 세부 수치는 미정이므로 러프하게(±1~2 가중치) 구현하고 튜닝 여지를 남긴다.

구현 파일: `src/engine/characterGen.ts` (`generateRandomCharacter()`), `src/data/names.ts`, `src/data/origins.ts`, `src/data/jobs.ts`.

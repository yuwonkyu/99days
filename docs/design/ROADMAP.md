## 4. 콘텐츠 확장 (999/999 목표, 장기)

지금은 시드 40개(≈184종 조합 렌더) / 엔딩 57개. 아키텍처(시드+낱말뱅크, 무드×타입 그리드)는 이미
갖췄으니 이후 세션에서 아래를 반복하며 늘려나간다 — 매번 새로 설계할 필요 없이 항목만 추가하면 됨:

- [ ] [situationSeeds.ts](../../src/data/situationSeeds.ts)에 버킷(모드×카테고리)당 시드 추가 (현재 2~3개/버킷 → 목표 늘리기)
- [ ] `TIME_MOODS`/`STRANGERS`/`THREATS`/`OMENS`/`NOISES` 같은 낱말 뱅크 항목 확충 — 뱅크 하나 늘릴 때마다 해당 시드들의 조합 수가 곱으로 늘어남
- [ ] 새 카테고리 후보 검토 (예: 가족/권력다툼 등) — 현재 7종(위기/생계/사교/수수께끼/공포/황당/호감)에서 확장
- [ ] [endings.ts](../../src/data/endings.ts)의 type×mood 셀마다 텍스트 추가
- [ ] 콘텐츠가 늘어날 때마다 `docs/design/04-ai-gamemaster-prompt.md`의 수치(시드/렌더/엔딩 개수)도 함께 갱신
